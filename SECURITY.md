# Security Policy

## Supported Versions

Security updates are provided for the latest release line only.

| Version | Supported |
| ------- | --------- |
| 0.5.x   | ✅        |
| < 0.5   | ❌        |

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub Security Advisories for this repository:

- Go to the **Security** tab in this repository
- Click **Report a vulnerability**
- Provide clear reproduction steps and impact details

Do not open public issues for potential vulnerabilities.
